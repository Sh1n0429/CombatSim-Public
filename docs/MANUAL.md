# Live・ARENAの使い方

## 対戦する

`uv run --frozen python -m scripts.live` を実行し、表示されたURLを同じPCで開きます。

1. 対戦方式を選びます。単一モデル同士、総当たり、機体ごとの混成チームに対応します。
2. ルール機なら「ルール / fix」または「ルール / random」を選びます。randomは試合のシードに応じて設定を抽選します。
3. 機数・シード・青赤交替・観戦速度を設定して開始します。機体ごとの混成チームには読み込んだモデルを割り当てます。

対戦の停止・再開は対戦設定画面で行います。観戦速度の初期値は `configs/application.json` にあります。
「1 tick/1秒」から加速表示・最速を選べます。計算が追いつかない場合は指定速度より遅くなります。

## 観戦する

ARENAは同じタブから切り替えられます。全体画面、機体ごとの追尾カメラとHUDが使えます。
音声は画面のボタンから有効にします。モデル別の色味・機体ラベルで同じチーム内も区別できます。
スライダーで巻き戻しても対戦は続くため、詳しく見る場合は対戦自体を一時停止します。

## モデルを読み込む

書き出し済みモデルは `models/任意の名前/` に `model.pth` と `metadata.json` を置きます。
起動中ならモデルライブラリの「モデルを追加」で、そのフォルダーを選択してください。
自分で保存したRLlibチェックポイントも読み込めます。

現在のモデル形式は `combatsim-model-v1`、識別子は `model_id` です。
この一般版の書き出しコマンドで作成したモデルを使ってください。
外部から受け取るモデルは重み専用形式で読みます。ネイティブのチェックポイントは自分で作成したものを使ってください。

## リプレイと結果

保存を有効にした試合の結果・HTMLリプレイは `artifacts/live/` に保存されます。
「完了した試合」から開き、同じ条件で再対戦できます。
「報酬の内訳」では表示中のtickの配点、上限で削られた量、機体別の累計を確認できます。
順位用の勝ち点は学習報酬とは別集計です。

終了時は対戦を停止し、起動したターミナルで Ctrl+C を押します。
